# Faculty Management System

A high-performance, minimalist Unified Exam Allocation Dashboard for academic institutions.

## Features
- **Automated Allocation**: Intelligently matches faculty to exam halls.
- **Substitute Tracking**: Identifies standby faculty for every session.
- **Professional PDF Reports**: Generates master time tables.
- **Clean Black UI**: Modern, dark-themed interface.

## Tech Stack
- **Backend**: FastAPI (Python)
- **Frontend**: React (Vite)
- **Database**: SQLite

## Deployment
This project is configured for deployment on Render.
